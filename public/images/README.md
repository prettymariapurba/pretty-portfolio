---

## 📐 Rekomendasi Ukuran

### Foto Profil

- **Minimal:** 300x300px
- **Ideal:** 500x500px
- Format: JPG, PNG, atau WebP
- Ratio: 1:1 (square)

### Screenshot Project

- **Minimal:** 800x600px
- **Ideal:** 1280x720px
- Format: JPG, PNG
- Ratio: 16:9 atau similar

## 🔗 Cara Referensi di Code

### Untuk Hero Profile Picture:

```typescript
// Di hero section, update URL:
src = "/assets/images/profile.jpg";
```

### Untuk Project Images:

```typescript
// Di project data array:
const projects = [
  {
    id: 1,
    image: "/assets/images/bimbel-farmasi.jpg",
  },
  // ...

```

## 💡 Tips Optimasi

1. **Kompres sebelum upload** → gunakan TinyPNG, ImageOptim
2. **Convert ke WebP** → format lebih kecil tanpa kehilangan kualitas
3. **Backup original** → simpan file asli di tempat aman
